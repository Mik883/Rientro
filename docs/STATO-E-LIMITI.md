# Stato e limiti

Versione preliminare gratuita proprietaria. Funzioni disponibili: Home Assistant e connettori diretti documentati, rilevamento tramite router,
conferma mobile monouso, ordine/attese, connettori smart, automazioni luci, diagnostica,
backup cifrato, storico e profili di più abitazioni nell'app. Il programma è gratuito.
Le modifiche alla configurazione richiedono i permessi amministratore.

Luci, prese, clima e riscaldamento: associazione in Home Assistant; le automazioni
implementate comandano le luci selezionate. Non promettere un controllo universale
di tutti i dispositivi o tutti i router. Le famiglie TIM/Vodafone/WINDTRE/Sky senza
modello e firmware non rappresentano compatibilità già collaudata.

Nessun server remoto Rientro pubblico. Nessuna registrazione automatica al titolare.
Le notifiche web possono usare servizi push esterni; Tailscale e integrazioni cloud
usano i rispettivi servizi. Non significa assenza totale di traffico Internet.
MacOS/iOS nativo non compilati. Webapp iOS richiede HTTPS attendibile e prove reali.
Windows EXE/setup privi di firma Authenticode commerciale. APK firmata release.
Le prove software non equivalgono al collaudo fisico su ogni impianto.
