# Third-party components

[Italiano](../../THIRD-PARTY.md) · **English**

The proprietary licence covers only original Rientro material. Third-party
components retain their own licences, modification/redistribution rights and
applicable source obligations. Rientro's resale restrictions do not override them.

The Windows runtime preserves Python's PSF/incorporated licences, package
`*.dist-info` notices and the Python sources of MPL-covered pywebpush, py-vapid
and certifi. The release also provides `Sorgenti-MPL-2.0.zip`. The separate
third-party licence bundle includes collected notices and Python/Android inventories.

Main components include Python, pywebview, FastAPI/Starlette/Uvicorn, cryptography,
pywebpush, py-vapid, certifi, pybticino, the adapted Aegis connector, PySwitchbot,
Bleak, WinRT dependencies and Lucide. AndroidX WebKit and its resolved dependencies
keep their upstream notices in the APK assets and licence bundle. Microsoft
WebView2 remains an external prerequisite subject to Microsoft's terms.

The technical inventory lists 61 Python distribution metadata entries, 69 collected
notice/licence files and 65 runtime binaries; the Android runtime graph contains
12 resolved components. This is not a comprehensive legal certification of every
binary, manufacturer API, cloud service or trademark. No per-copy royalty was
identified in the examined open-source library texts. External service costs and
conditions are separate. Tailscale is not redistributed as a bundled VPN service.
