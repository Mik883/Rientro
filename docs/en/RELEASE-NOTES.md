# Rientro 2.0.1 — pre-release

[Italiano](../../CHANGELOG.md) · **English**

Rientro is free proprietary software owned by Michele Perrino, not open source.

- Windows program, signed Android app and web interface.
- Gate, alarm and smart lock, with configurable action order and delays.
- Home Assistant or documented compatible direct connectors.
- Router-based presence, authenticated one-time phone confirmation and user roles.
- Smart connectors, Home Assistant light automations, diagnostics, alerts,
  encrypted configuration backups and history.
- Home-network access, or Tailscale configured by the user for remote access.
- Italian and English documentation; application interface currently in Italian.

Validation: 229 software tests passed, one skipped. Real iOS notification and
new device-model tests remain pending. Windows executables do not have an
Authenticode signature. Software tests are not universal hardware certification.


Updated visual identity, light/dark wordmarks, app icon and blue–turquoise accent palette. Existing features and settings are preserved.
