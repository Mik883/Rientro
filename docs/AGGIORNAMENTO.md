# Manutenzione dell'installazione

Prima di sostituire i file del programma, crea una copia protetta del profilo
`%USERPROFILE%/RientroData/Public` e chiudi Rientro.

Su Windows esegui il setup ufficiale oppure estrai completamente il portable.
Non cancellare il profilo dati. Su Android conserva l'app installata quando
installi un APK ufficiale firmato con la stessa identità.

Conserva i dati di associazione in modo sicuro. Se cambi indirizzo HTTPS,
può essere necessario associare nuovamente il telefono. Per l'accesso da fuori
casa configura Tailscale sul PC e sul dispositivo mobile.
